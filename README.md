# VectorShift Frontend Technical Assessment — Pipeline Builder

A highly interactive, full-stack node-based pipeline builder application that allows users to seamlessly design, modify, and analyze complex logical workflows. Built using **React** and **React Flow** on the frontend, and **Python (FastAPI)** on the backend.

---

## 🚀 Architectural Blueprint & Key Features

### Part 1 & 2: Node Abstraction & SaaS Styling
* **`BaseNode.js` Abstraction Layer:** Engineered a centralized, highly reusable base wrapper to encapsulate shared lifecycle methods, connection handle distribution, delete controls, and consistent structural layout across the platform. This prevents code duplication and maximizes future expandability.
* **9 Production-Ready Nodes:** Successfully refactored the original 4 nodes (`InputNode`, `OutputNode`, `LLMNode`, `TextNode`) and introduced **5 brand-new custom nodes** leveraging the new abstraction:
  * `ConditionNode` (Logic branching)
  * `DatabaseNode` (Storage layer operations)
  * `WebhookNode` (Event-driven API integrations)
  * `TransformNode` (Data payload parsing/manipulation)
  * `DelayNode` (Time-based execution management)
* **Unified SaaS Premium Theme:** Replaced standard layouts with a polished, modern developer interface featuring soft depth shadows, rounded aesthetic borders, smooth hover animations, and vibrant functional color-coding for rapid visual categorization.

### Part 3: Intelligent Text Node Logic
* **Dynamic Dimensions:** Implemented auto-resizing canvas heights and widths on the `<textarea>` component based on length of input text, ensuring absolute readability without clumsy browser handles.
* **Real-time Variable Parsing:** Embedded a reactive RegEx pattern watcher looking for valid JavaScript variable strings wrapped in double curly brackets `{{ variable_name }}`.
* **Dynamic Left Edge Handles:** On discovery of any unique variable string, a new connection input handle is instantly instantiated down the left edge, perfectly distributed without interrupting standard text focus or cursor states.

### Part 4: End-to-End Backend Verification (DAG Checker)
* **Full-Stack State Ingestion:** Wired up the `Submit Pipeline` action to harvest the complete canvas arrays for nodes and edges directly from a centralized state provider.
* **Cycle-Detection Engine (DAG Check):** Configured a FastAPI backend gateway running an optimized Depth-First Search (DFS) graph traversal to process incoming node layouts and instantly alert users if their setup contains infinite circular loops or forms a valid **Directed Acyclic Graph (DAG)**.

### 💎 V2 UX Enhancements Added
* **Asynchronous Toast System:** Integrated `react-hot-toast` to dismiss standard browser popups. Canvas analysis notifications slide onto screen natively with success and error indicators.
* **Component Deletion Actions:** Added functional delete closures directly into the `BaseNode` headers, giving users quick-action removal capabilities for any chosen node.
* **Intelligent Connections:** Configured client-side rules to block self-loops and invalid connection states immediately on user drop.

## 🛠️ Project Execution & Set Up

Ensure you have [Node.js](https://nodejs.org/) and [Python 3.9+](https://www.python.org/) installed before running the split environments.

### 💻 Frontend (React Server)
1. Open your terminal and change directories into the frontend application:
   ```bash
  cd frontend

   ```


2. Install the necessary package dependencies (including `reactflow`, `zustand`, and `react-hot-toast`):
   
```bash
npm install

```


3. Boot up the local development canvas environment:
```bash
npm start

```


4. Open [http://localhost:3000](https://www.google.com/search?q=http://localhost:3000) to view it live in your browser.

### 🐍 Backend (FastAPI Server)

1. Open a separate running instance of your terminal and navigate to the backend folder:
```bash
cd backend

```


2. Install the API prerequisites:
```bash
pip install fastapi uvicorn

```


3. Start the live-reloading ASGI application runner:
```bash
uvicorn main:app --reload

```


4. The server runs securely on port `8000` (`http://127.0.0.1:8000`), automatically accommodating CORS validation headers generated by your React frontend client.
